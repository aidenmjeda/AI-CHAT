# AI Web App

A **full-stack AI web application** built with **React.js**, **Node.js**, **OpenAI API**, and **ImageKit**. Ask questions, get AI-powered responses, and generate images directly from the chat interface.

## Demo

Check out the live demo: [coming soon](#)

## Features

- Interactive AI chat powered by Gemini
- Image generation with ImageKit
- Responsive UI with React.js
- Full-stack backend using Node.js and Express
- Easily extendable for additional AI functionalities

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aidenmjeda/AI-CHAT.git

2. Navigate to the project directory:
    cd AI-CHAT

Install dependencies for both client and server:

# Client
cd client
npm install

# Server
cd ../server
npm install

Set up environment variables:

    Server: Create a .env file in the server folder:


JWT_SECRET = 'your_JWT_API_KEY'
MONGODB_URI = your_mongodb_api key
GEMINI_API_KEY = your_gemini_api_key

Start the application:

    # Start server
    cd server
    npm run dev

    # Start client
    cd ../client
    npm run dev

    Open your browser at http://localhost:3000

Technologies Used

    Frontend: React.js, HTML, CSS, JavaScript

    Backend: Node.js, Express

    AI & API: Gemini API, ImageKit

    Database (Optional): MongoDB for chat history

Usage

    Start the app and interact with the AI chatbot via the web interface.

    Generate AI-powered text responses and images.

    Extend the project with new AI tools and functionalities.
